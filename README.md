# Blood Dragon Menu

Главное меню и экран «Справка и параметры» в стиле Far Cry 3: Blood Dragon для **Godot 4.7 .NET (C#)**.

Спецификация: [`game_menu_specification.md`](game_menu_specification.md).

## Требования

- Godot **4.7** (.NET / C#), рекомендуется **4.7.2**
- **.NET 8** SDK

## Запуск

1. Откройте папку проекта в Godot 4.7 (.NET).
2. Дождитесь восстановления NuGet / сборки C#.
3. Запустите сцену `scenes/main_menu/MainMenu.tscn` (она же главная сцена проекта).

## Что внутри

| Экран | Описание |
|--------|----------|
| Главное меню | Заголовок с мигающим курсором, кнопки кампании / настроек / выхода, CRT-оверлей |
| Справка и параметры | Две колонки: категории слева, панель настроек справа |

Категории настроек:

- Изображение, калибровка, качество видео
- Управление (включая переназначение клавиш)
- Игровой процесс
- Язык (интерфейс, озвучка, субтитры, размер шрифта)
- Звук (шины Master / Music / SFX / Dialogue / Ambient)
- Руководство и титры

Настройки пишутся в `user://settings.cfg` и применяются через autoload `SettingsManager`.

Появление кнопок главного меню использует **Control offset transforms** из Godot 4.7 (анимация не ломает layout `VBoxContainer`). Геймпад игнорируется, пока окно не в фокусе.

## Структура

```
scenes/     сцены меню и заглушка игрового уровня
scripts/    C#: меню, настройки, аудио, графика
shaders/    CRT, glow, калибровка
audio/      эмбиент меню и UI-звуки
```
